# Atlas v0.1.0

First self-hostable Atlas release: a PostgreSQL-backed engineering and web operations dashboard with independent named layouts, drag/reorder/resize controls, light/dark themes and a vendored Stoa design system.

Nine cards cover performance, real users, SEO, region latency, repository quality, releases, errors, opt-in AI usage and derived anomalies. Collectors share CLI/API execution, persisted history and duplicate-run locks. Optional inputs remain explicitly missing until configured; synthetic demo fixtures live in a reserved isolated schema.

Production supports shared-password or trusted-header authentication, signed sessions, CSRF-protected writes and collection-only scheduler tokens. Open mode is limited to loopback development.

Download `atlas-0.1.0-source.tar.gz` and `SHA256SUMS`, verify the checksum and follow [deployment instructions](../DEPLOYMENT.md). The archive includes locked dependencies metadata, vendored design assets, SQL migrations, collectors, fixtures, a standalone launcher and Docker Compose configuration. Node 24, pnpm 9.8.0 and PostgreSQL 14+ are supported. Provider availability and required keys vary by collector; see [collector configuration](../COLLECTORS.md).

The public Pages canvas remains an illustrative static demo. It does not connect to a private Atlas database. This release uses a shared team identity for password auth, forward-only database migrations and explicit opt-in local AI usage sources.
